This project is built around a simple split:

- Portfolio information lives in `src/data/profile.ts`.
- Blog articles live in `src/content/posts`.
- Selected Obsidian notes can be synced into the posts collection with `npm run sync:obsidian`.

The result is a site that stays GitHub-friendly while letting the writing workflow remain Markdown-first.
