Two Habits,
Four Techniques.

MinLi's progressive-discipline framework — what makes Codex's 50-line /goal prompt industrial-grade.

The Two Habits — Posture
Habit 01
Start with a verb, not a role description.
Habit 02
State as lists, not sentences.
The Four Techniques — Enforcement
01
Type your inputs
Wrap user content in <untrusted_objective> tags. Label data as data, not instructions. One XML tag stops prompt injection.
02
Replace adverbs with nouns
Drop "carefully verify." Enumerate the noun list: every requirement, file, command, test, gate, deliverable. A list is a checklist; an adverb isn't.
03
Flip the default
One sentence: "Treat uncertainty as not achieved." Move the decision boundary, not the personality.
04
Stop ≠ complete
Budget exhausted is not "done." Ship a separate budget_limit.md so the model can't claim victory under pressure.
